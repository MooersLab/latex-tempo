latex-tempo and org-tempo keys compared

latex-tempo keys in LaTeX buffers

\index{latex-tempo!key table}

These keys come from latex-tempo version 0.5.0. Type the key at the start of a line and press TAB, or press C-c C-, and then the key letter. The keys are case sensitive.

The width prompt for <f defaults to 0.8. The <t prompts default to 2 body rows and 5 columns.

org-tempo keys in Org buffers

\index{org-tempo!key table}\index{org-structure-template-alist}

These keys are the defaults in Org 9.6. Load them with (require 'org-tempo). The block keys come from org-structure-template-alist and are also offered by C-c C-, (org-insert-structure-template). The keyword keys come from org-tempo-keywords-alist. The <I key is defined in org-tempo itself.

Side-by-side comparison

\index{latex-tempo!comparison with org-tempo}

Table 3: Meaning of each key in latex-tempo and in org-tempo.
Key latex-tempo org-tempo Same purpose
<a verbatim environment export ascii block close
<c center environment center block yes
<C comment environment comment block yes
<e enumerate list, five items example block no
<E comment with a note line export block close
<f figure (none) new
<h comment with a note line export html block close
<i itemize list, five items #+index: keyword no
<I new \item #+include: keyword no
<k checklist, five items (none) new
<l raw LaTeX marker comments export latex block close
<m minted environment (none) new
<p \paragraph{} (none) new
<q quote environment quote block yes
<s (none) src block moved to <m
<t booktabs table (none) new
<u \subsection{} (none) new
<v verbatim environment verse block no
<x \index{} (none) new
<y \subsubsection{} (none) new
<A (none) #+ascii: keyword Org only
<H (none) #+html: keyword Org only
<L (none) #+latex: keyword Org only

Four keys have the same purpose in both packages, namely <c, <C, <q and the source block, which is <s in Org and <m in latex-tempo. Four keys change meaning between the two, namely <e, <i, <I and <v. The <s key does nothing in latex-tempo. These differences are worth remembering when you switch between Org and LaTeX buffers.
